The Platforms

Not four separate businesses — proof the chassis works in four hard domains. The common thread: regulated, field-heavy operations where generic SaaS fails. Every engagement starts from one of these.

iPhone App + Web Workspace

VOSS

An AI clinical documentation partner for physicians — live on the App Store as VOSS Neuro, with a companion web workspace at app.vossclinical.com. VOSS records the encounter, transcribes it live with clinician/patient speaker labels, and generates a structured, specialty-aware clinical note plus ranked possible explanations and a plain-language summary patients can actually use. The clinician reviews, edits, and signs every note.

  • ✓ Ambient encounter recording with live transcription — real-time speaker labelling, with automatic batch fallback
  • ✓ 22 medical specialties mapped to six note templates — neurology with full neurological-exam sections, plus cardiovascular, musculoskeletal, mental health, and systems-based notes
  • ✓ Possible explanations — likelihood-ranked with rationale, red flags, and suggested workup
  • ✓ Patient-friendly summaries with on-demand translation into seven languages
  • ✓ Patient mode: an AI health companion with text and voice chat, plus a Visit Prep handout to bring to appointments
  • ✓ Web workspace — record in the browser, sync sessions from iPhone, edit transcripts, manage versions, export PDF/JSON
  • ✓ Clinician in control — immutable note versioning, sign-off, transcript editing, and post-visit context injection

Built for clinical privacy. Encrypted in transit. Audio deleted immediately after transcription by default. No server-side retention of clinical content. No analytics or tracking SDKs. Every note reviewed and signed by the clinician.

Web Platform

Drillr

Professional borehole logging software for environmental geologists who work where the internet doesn't. Drillr is an offline-first field platform that captures detailed stratigraphic data, generates client-ready PDF and Excel reports in one tap, and syncs to the cloud the moment you're back online — across iPad, iPhone, Android, and desktop.

  • ✓ Offline-first PWA — log boreholes in the field with zero connectivity, sync automatically when back online
  • ✓ Full stratigraphic logging: lithology, intervals, inclusions, chemistry, and photos per layer
  • ✓ Multiple classification standards built in — USCS, CSSC, BS 5930, ASTM D2488, plus custom codes for team standardization
  • ✓ One-tap professional PDF reports with graphic stratigraphic columns and lithology patterns
  • ✓ Excel export (GRYD-compatible) for downstream analysis and lab integration
  • ✓ Munsell color picker, SPT blow-count capture, and GPS coordinates with UTM ↔ WGS84 conversion
  • ✓ Interactive Mapbox-powered project maps with borehole plotting
  • ✓ Side-by-side log comparison across boreholes in a project
  • ✓ Installs like a native app — no App Store required, no IT approval needed

Excel Add-in — Desktop & Web

GRYD

Smarter analysis. Faster remediation. GRYD lives inside the Excel workbooks environmental teams already use — normalizing messy lab data, screening it against multi-tiered regulatory guidelines, and producing defensible, audit-ready reports. Built for wellsite closures, agricultural salinity assessments, and contaminated-site remediation. No uploads. Your data never leaves the workbook.

  • ✓ Automated exceedance screening across soil, groundwater, and surface water — Alberta Tier 1, Tier 2A, CCME, and BC CSR guideline packs, version-stamped per run
  • ✓ Conversion Analysis engine — lab EDD auto-detection, analyte alias mapping, unit normalization, salinity and PHC reconciliation, coordinate systems
  • ✓ Ask GRYD — an AI co-pilot grounded in your active screening run, with row-level citations and org-configurable inference
  • ✓ Site-specific background calibration — depth-bin P95, delta-shift overrides, and non-detect statistics (Kaplan-Meier, ROS, DL/2)
  • ✓ Visual Forensics Suite — 25+ specialty charts, from Piper and Stiff to source discrimination and chlorinated-solvent decay tracking
  • ✓ Excel-native GIS — plume mapping, ATS grid overlays, site-area zones, and excavation soil-volume calculations
  • ✓ Versioned run history — re-screen pathway scenarios on a locked dataset without re-importing, with side-by-side run diffs

GRYD Highlights

  • Live in Excel Desktop (Windows & Mac) and Excel for Web via Microsoft 365 — install same day, no IT integration project
  • The middle ground between enterprise EDMS deployments and manual spreadsheets — for environmental scientists, consultants, geologists, engineers, and agrologists
  • Local-first privacy: lab data and results stay in the workbook; Microsoft Entra ID sign-in with an enterprise security posture
  • Per-project pricing that scales from single-site assessments to enterprise portfolios

Enterprise SaaS

Tymr

Timesheets that fill themselves. Tymr drafts everyone's time from the tools where work already happens — so people confirm their week in under a minute, and the company finally sees real hours, capacity, and cost. Every hour of work, human or AI agent, flows through one auditable ledger: the capacity system of record for regulated workforce time attribution.

  • ✓ Zero-entry capture from nine source systems — calendar, chat, ticketing, dev, ITSM, and HRIS
  • ✓ UTEv1 — an open, vendor-neutral Universal Time Event standard; append-only, lineage-preserving, one schema for humans and AI agents
  • ✓ AI agents as first-class workers — agent SDKs for TypeScript and Python with token-level cost
  • ✓ Live virtual floor with real-time meeting and incident cost tickers — optional, with privacy-first visibility controls
  • ✓ Capacity, utilization, and true project cost — EVM project health, portfolio scenarios, and live OpEx/CapEx classification
  • ✓ One ledger, multiple regulatory cuts — R&D tax credit packs (IRC §41/§174, SR&ED), ASC 350-40 capitalization workpapers, and DCAA-grade audit trails as byproducts
  • ✓ Privacy Shield by design — private My Time review, self-only defaults, no keystroke or message-content tracking
