Drillr

Professional borehole logging software built for environmental geologists who work where the internet doesn't. Drillr is an offline-first platform that lets you capture detailed geological data in the field, generate PDF reports in one tap, and sync everything when you're back online.

  • ✓ Offline-first borehole logging with automatic sync
  • ✓ Record stratigraphy, lithology, and geological classifications
  • ✓ One-tap professional PDF report generation
  • ✓ Interactive maps with coordinate plotting
  • ✓ Photo capture with automatic compression
  • ✓ Custom classification codes for team standardization
